Follow these simple steps to install the modpack and join our server smoothly.

## A quick heads-up about launchers:

* **Using TLauncher?** We highly recommend switching to **TLegacy** or **SKLauncher**. TLauncher forces a "TLSkins" mod that you can't delete, and it will cause some annoying issues with our modpack.
* **Using the default Minecraft Launcher?** To make your life a lot easier, we suggest switching to **Modrinth, CurseForge, Prism, or ATLauncher** so you can easily import the modpack.
* *Note for ATLauncher or Prism Launcher users:* Make sure you download the **CurseForge** file version to import into your launcher!

## Step 1: Download the Modpack

Grab the modpack file from our Discord server.

## Step 2.1: Installing

**For Modrinth, CurseForge, ATLauncher, & Prism Launcher**

* Open up your launcher.
* Go to your Instances/Profiles tab and import the file you downloaded in Step 1.

> *(**If you're using Modrinth**, it's even easier: just double-click the `.mrpack` file and it will install automatically!)*

* Sit back and wait for the installation to finish.

## Step 2.2: Installing

**For TLegacy**

* Open your TLegacy launcher.
* Make sure you downloaded the `.rar` version of the modpack from Step 1.
* Watch this quick tutorial video and follow the steps carefully: <https://youtu.be/d34pDKUaFCY>
* Wait for the installation to finish.

## IMPORTANT KNOWN ISSUE Currently, there is a bug that will cause your entire game to crash if you open the Resource Packs menu or if you disconnect from the server. There's no fix for this right now. Because of this, please make sure to apply any of your personal resource packs from the Main Menu **before you join the server**, not while you are actively playing! We suggest informing both existing and new players about this.

This is a known issue and a fix is planned.

## Step 3: Connect to the Server

When you boot up the game and go to Multiplayer, our server should already be on your list so you can jump right in! But just in case it's missing, you can add it manually using our IP: `play.floreon.garden`

## Step 4: Need Help?

If you run into any problems or notice missing mods, don't worry! Just open a ticket, and we’ll be happy to help you out.
