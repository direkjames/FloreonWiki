Floreon is a Philippine-based Minecraft Cobblemon server made for relaxed, peaceful play: slow progression, a friendly community and no rush.

> [!NOTE] Server info
> Java Edition, Fabric 1.21.1. Server address: `play.floreon.garden`

## Basic commands

| Command | What it does |
|---|---|
| `/spawn` | Go to the spawn |
| `/home set <name>` | Save a home where you stand |
| `/home tp <name>` | Teleport to one of your homes |
| `/tpa <player>` | Ask to teleport to a player |
| `/tpahere <player>` | Ask a player to teleport to you |
| `/rtp` | Teleport to a random place in the Overworld |
| `/warp tp <name>` | Go to a warp |
| `/gts` | Open the Global Trading System |
| `/vote` | See the voting links |
