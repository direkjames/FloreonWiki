You can put custom music files in Music Discs and play them using the Jukebox. The maximum size is 50MB per file and the maximum length is 30 minutes.

## Uploading audio files via URL

Run `/audioplayer url "https://example.com/myaudio.mp3"` where `https://example.com/myaudio.mp3` is the link to your **.mp3** or **.wav** file.

> [!WARNING]
> This method doesn't always work, so we suggest just downloading the music file and following the steps below.

## Uploading audio files via Filebin

Run `/audioplayer filebin` and follow the instructions.
