## 1. Building your first display

1. Build a screen out of **black concrete**
2. Select the area with a **diamond axe** by left-clicking the first corner and then right-clicking the opposite corner
3. Type `/display create` while looking on it
4. `Sneak (Shift) + RMB` to open its menu, and paste a video link into the search box

That's it — the video starts playing!

> [!WARNING]
> The limit is one display per player.

## 2. The display menu

`Sneak + right-click` a display to open its menu. It has three parts: **a preview panel**, **a settings panel**, and **a search / suggestions panel**.

![Display: screenshot 2](/images/display-2.webp)

## 3. Preview panel

![Display: screenshot 3](/images/display-3.webp)

* Mute button and a volume slider (0–200%)
* Seek bar with hover thumbnails (scrub preview)
* Audio track button — only shows up if the video actually has more than one audio language / track available
* Popout (read below)
* Play / Pause

![Display: screenshot 4](/images/display-4.webp)

### Popout

The popout button gives you four ways to watch outside the normal in-world view:

**Window** — plays in a separate window on your desktop  
**In-game** — a picture-in-picture overlay that follows you around  
**Fullscreen** — takes over your screen, letterboxed  
**Borderless** — takes over your screen edge-to-edge

## 4. Settings panel

![Display: screenshot 5](/images/display-5.webp)

| Setting         | What it does                                                           |
| --------------- | ---------------------------------------------------------------------- |
| Render distance | How far away this display keeps rendering for you (2–12 chunks)        |
| Quality         | Steps through whatever quality ladder the source video actually offers |
| Brightness      | 0–100%                                                                 |
| 3D Audio        | Off / Enhanced / Advanced — see below                                  |
| Synchronization | Local / Synced / Broadcast — see below                                 |

### 3D / environmental audio

**Off** — flat, distance-only volume falloff  
**Enhanced** — loudness normalization, stereo panning, raytraced occlusion (walls actually muffle the sound), distance air absorption, and reverb  
**Advanced** — maximum audio realism

### Synchronization modes

**Local** — playback state (play / pause / seek) is per-player; only you control what you see  
**Synced** — everyone watching the display sees the same play / pause / position, kept in sync by the server  
**Broadcast** — a persistent, always-looping, locked, quality-capped mode meant for ambient screens / lobby ads. Nobody can pause or seek it

## 5. Owner controls

If you own the display, you'll also see:

**Lock** — prevents other players from changing the video or settings  
**Delete** — removes the display  
**Report** — only shown if the server has reporting enabled; flags the current video to the server's moderation team
