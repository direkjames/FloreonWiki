Xerneas is summoned at the **Tree of Life**. You need to collect Aurora Essence and bring it to the **Aurora X Log**.

## What you need

- **Empty Jars**, crafted from **5 glass**:

| | | |
|---|---|---|
| Glass | | Glass |
| Glass | | Glass |
| | Glass | |

- **16 Aurora Essence Jars**, filled with Aurora Essence

## How to do it

1. Craft some **Jars**.
2. Find **Aurora Essence** out in the world. It is a glowing block with floating particles.
3. Right-click the Aurora Essence with an empty Jar to capture it. You get an **Aurora Essence Jar**. Without an empty Jar, you cannot take it.
4. Collect **16** Aurora Essence Jars.
5. Go to the **Tree of Life** and right-click the **Aurora X Log** with the jars. The log uses them up, wakes up, and Xerneas appears.
